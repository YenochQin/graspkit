# 博士研究进展报告

**题目：** 基于 GRASP2018 计算结果处理与人工神经网络组态筛选的原子结构计算方法研究

本阶段研究工作主要围绕两个彼此衔接、逐步推进的方向展开。第一部分聚焦于 GRASP2018 程序计算结果的处理、整理与分析，目标是解决原始输出数据格式复杂、信息分散、后处理效率低的问题，建立统一的数据解析与分析框架。第二部分在第一部分工作的基础上，进一步面向大规模组态相互作用计算中的“组态数爆炸”问题，引入人工神经网络方法，对组态态函数进行智能筛选，以提高计算效率并保持物理结果的可靠性。两部分工作之间具有明确的递进关系：前者为后者提供数据基础、特征表达和分析支撑，后者则是前者在方法层面的深化与拓展。

## 一、GRASP2018 程序计算结果的处理与分析

GRASP2018 是相对论原子结构计算的重要程序，其输出包含能级、混合系数、LSJ 组成、跃迁数据、径向波函数等多种物理信息。然而，这些结果通常以文本文件和二进制文件混合存储，不同模块输出格式差异较大，直接用于后续分析存在较大困难。因此，本阶段首先围绕 GRASP2018 输出结果建立了系统化的数据处理框架。

在具体工作上，首先完成了对多类 GRASP 输出文件的统一解析，包括能级文件、混合系数文件、LSJ 成分文件、跃迁文件、CSF 文件以及径向波函数文件等。通过模块化加载器设计，不同类型文件被转换为统一的数据对象或表格结构，从而显著降低了后续分析的复杂度。其次，在数据提取与整理方面，围绕能级和组态信息实现了配置字符串规范化、LSJ 耦合信息提取、多轮计算结果对比、跃迁数据匹配与定位等功能，使原始计算结果能够更方便地转化为适合物理分析与论文展示的结构化数据。

在此基础上，我进一步开展了面向 CSF 的特征表达工作。针对每一个组态态函数，程序提取其轨道占据、耦合中间量和最终角动量信息，构造具有固定长度的数值描述符。该描述符不仅保留了组态的主要物理特征，而且实现了从符号化原子组态到数值向量的转换，为后续机器学习模型的训练奠定了直接基础。此外，围绕能级、跃迁和波函数等结果，还建立了相应的后处理与可视化能力，使得计算结果能够支持进一步的物理解释、误差分析与图表输出。

总体来看，这一阶段完成了从“原始 GRASP 输出”到“可分析、可比较、可建模数据”的转化，解决了以往人工整理工作量大、重复性强、跨轮次结果难追踪的问题。更重要的是，这一部分工作并不仅仅是工具层面的整理，而是为下一步的智能筛选研究提供了规范的数据接口、稳定的标签来源以及可解释的组态特征表示。

## 二、基于 ANN 的组态筛选研究

在完成 GRASP2018 结果处理框架后，研究工作进一步转向计算流程中的核心瓶颈问题，即大规模组态相互作用计算中 CSF 数量迅速膨胀，导致计算成本显著增加。传统做法主要依赖经验截断或人工挑选，但在复杂原子体系中，这种方式往往难以兼顾效率与精度。因此，本阶段尝试引入人工神经网络方法，对组态进行自动筛选和优先排序，以提高计算资源利用效率。

这一部分工作的关键前提，正是第一部分建立的 CSF 描述符体系。通过将每个 CSF 表示为具有明确物理含义的数值向量，可以将“组态是否重要”的判别问题转化为一个监督学习问题。基于这一思路，我构建了面向 CSF 筛选的 ANN 模型，并将已计算组态的混合系数信息作为监督信号，训练模型识别哪些组态更可能对目标能级产生重要贡献。

在这一过程中，我还配套建设并使用了 `rCSFs` 这一基于 Rust 的高性能 CSF 预处理库，作为 ANN 筛选流程的重要上游支撑。该库并不直接承担模型训练，而是聚焦于两个基础性环节：其一，将大规模 CSF 文本文件以流式、并行、保序的方式转换为 Parquet 列式数据，从而显著降低后续数据读取与管理成本；其二，依据头文件中的 peel subshell 信息，直接从 Parquet 数据批量生成定长描述符表，并输出适合 Polars 与 NumPy 使用的列式结果。通过这一设计，原本由 Python 单独承担的大规模文本解析与描述符生成任务，被前移到 Rust 实现的高吞吐流水线上，为 ANN 训练阶段提供了更稳定、更高效的数据入口。

其中，描述符归一化方案是本阶段 ANN 筛选研究中的一个重点工作。原始 CSF 描述符由各子壳层对应的三元组构成，即占据电子数 \(n_i\)、子壳层内部角动量 \(2Q_i\) 和沿耦合链逐步累积得到的角动量 \(2J_{cum,i}\)。如果直接将这些原始整数特征送入神经网络，不同壳层之间由于容量不同、占据状态不同以及耦合位置不同，会导致特征尺度差异较大，进而影响模型训练的稳定性与不同样本之间的可比性。为此，我在 `rCSFs` 中实现了面向单个 CSF 的物理归一化方案，将每个三元组分别按照其对应的物理上界映射到统一尺度。

具体而言，首先对占据数 \(n_i\) 采用壳层容量归一化，即以该子壳层的最大允许电子数 \(g_i=2|\kappa_i|\) 为分母，将其转化为壳层填充分数 \(n_i/g_i\)。这样处理后，不同轨道类型上的占据情况都被映射到 0 到 1 的共同区间，具有明确的物理含义。其次，对内部角动量 \(2Q_i\) 的归一化不再采用固定常数，而是采用与当前占据数直接相关的上界 \(n_i(g_i-n_i)\)。这一处理保留了粒子—空穴对称性，也避免了传统固定上界在非半满占据时造成的尺度压缩问题，使得不同占据状态下的角动量特征仍能在统一标准下比较。

更关键的是，对累积耦合角动量 \(2J_{cum,i}\) 的归一化，我没有简单使用全局固定分母，而是结合当前 CSF 的目标总角动量 \(2J_{target}\) 以及各子壳层可能提供的耦合余量，构造位置相关的约束上界。具体做法是：先由各壳层的占据情况构造局部耦合上限，再通过前缀和与后缀和分别表示某一位置之前和之后耦合链能够提供的角动量范围，最终以 \(\min(prefix_i,\ 2J_{target}+suffix_i)\) 作为第 \(i\) 个位置累积角动量的归一化分母。这样一来，描述符最后一项不再是简单的“数值大小”，而是转化为“相对于该耦合位置理论允许范围的占比”，更符合 CSF 耦合链本身的物理结构。

这一归一化方案的意义主要体现在三个方面。首先，它将原始描述符从量纲和范围都不一致的整数特征，转变为带有明确物理约束、且整体落在统一尺度内的连续特征，提高了 ANN 训练的数值稳定性。其次，它增强了不同 CSF 之间的横向可比性，使模型学习到的模式更接近“相对重要性”而非“绝对数值大小”。再次，这一方案保留了每一项特征背后的物理解释，使得后续模型筛选出的高重要性组态仍可以回到壳层占据、内部耦合与累积耦合三个层面进行解释，而不是成为纯粹黑箱化的统计结果。可以说，这一归一化步骤是将“原始 CSF 数据”真正转化为“适合机器学习学习的物理特征”的关键中间桥梁。

在模型设计上，目前已经实现了两类主要思路：一类是标准全连接 ANN，用于较稳定地完成多标签分类任务；另一类是面向结构化特征的张量网络形式，用于进一步挖掘轨道间的耦合关系。训练过程中，模型不再局限于单个能级，而是支持多目标能级联合学习，从而提高了样本利用率，也增强了模型对不同谱项重要组态的综合识别能力。除分类路线外，还探索了回归路线，即直接预测组态贡献量的连续值，以保留更细粒度的排序信息。

在应用流程上，当前已经形成了“GRASP 计算—结果回收—ANN 训练—全空间预测—新组态采样—再次计算”的迭代式闭环。每一轮计算得到的新结果都会反馈到训练集中，用于更新模型，再由模型对未计算组态进行筛选和扩展。与此同时，为了避免单纯依赖机器学习打分而偏离物理目标，又引入了参考能级约束与混合排序策略，将模型预测结果与能级误差修正信息结合起来，提高筛选结果的稳定性和物理可信度。

从当前进展看，这一阶段已经不再停留在单纯的模型搭建，而是形成了较完整的组态智能筛选原型流程：能够从已计算数据中构造标签，训练神经网络模型，对未计算组态进行预测，并把筛选结果重新送回 GRASP 计算链条中。换言之，研究已经从“数据处理与表征”推进到了“数据驱动的计算优化”阶段。

因此，就方法体系而言，当前 ANN 组态筛选研究实际上已经形成了“GraspKit + rCSFs”的分层协同结构：前者负责 GRASP 结果回收、标签构造、模型训练、预测评估与迭代筛选调度，后者负责海量 CSF 文本到高质量描述符数据的高性能转换与归一化表达。二者结合后，研究工作不再局限于单一模型层面的算法尝试，而是进一步发展为一个兼顾物理可解释性、数据工程能力和迭代计算效率的完整筛选框架。

## 三、两部分工作的递进关系与阶段总结

两部分工作的逻辑关系是清晰且递进的。第一部分解决的是“如何把 GRASP2018 的复杂输出结果转变为可处理、可分析、可建模的数据”；第二部分解决的是“在已有数据基础上，如何进一步利用机器学习提高组态筛选效率”。前者构成后者的前提，后者则体现前者的应用深化。没有前一阶段对数据结构、结果解析和 CSF 描述符的系统整理，后一阶段的 ANN 模型就缺乏可靠输入与监督依据；而后一阶段的开展，也反过来验证了前一阶段数据处理框架的有效性与扩展价值。

因此，可以将当前博士阶段工作概括为：首先完成了面向 GRASP2018 结果的统一处理与分析平台建设，其次在此基础上初步建立了基于 ANN 的组态筛选方法与迭代计算流程。这两部分共同构成了“原子结构计算结果处理—特征表达—智能筛选优化”的完整研究链条，也为后续面向更复杂原子体系的高精度计算奠定了方法基础。

## 四、下一步工作计划

下一阶段的工作重点将集中在三个方面：一是进一步完善基于物理约束的标签构造、描述符归一化与筛选准则，提高模型训练目标与实际物理需求之间的一致性；二是在更多实际原子体系上验证 ANN 筛选策略及归一化方案对模型稳定性、泛化性与计算收益的影响；三是将目前形成的方法体系进一步凝练为论文成果，分别从“GRASP 数据处理框架”和“ANN 组态筛选方法”两个层面总结其学术贡献。
