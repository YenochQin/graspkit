# 博士研究进展报告

**课题方向**：基于机器学习优化的相对论原子结构计算方法研究
**代码载体**：GraspKit（v3.2dev2）
**报告日期**：2026 年 4 月

## 摘要

本阶段工作围绕 GRASP2018 的计算结果处理与组态优化展开，可分为两个递进的阶段。**第一阶段**针对 GRASP2018 原生数据处理能力不足的问题，建立了统一的数据解析、提取、分析与可视化框架，为后续研究奠定数据基础；**第二阶段**在此基础上，针对大规模组态相互作用计算中组态态函数（Configuration State Function, CSF）规模爆炸的瓶颈，提出并实现了基于人工神经网络（ANN）的 CSF 智能筛选迭代管道，为大原子体系的高精度计算提供了可行路径。

---

## 第一部分：GRASP2018 计算结果的数据处理与分析

### 1.1 研究背景与问题

GRASP2018 是相对论原子结构计算的主流程序，其输出涵盖波函数、能级、混合系数、跃迁数据等核心物理信息，但存在三方面不足：

1. **文件格式异构**：二进制与文本混合，不同计算阶段输出口径不一；
2. **后处理能力有限**：缺乏对多轮迭代结果进行追踪、比较与可视化的手段；
3. **与现代数据生态脱节**：难以直接对接 Pandas/Polars、HDF5/Parquet 等分析工具。

因此，本阶段首要目标是构建一套**面向科研分析的 GRASP 数据处理流水线**。

### 1.2 做了什么

本阶段完成的主要工作包括：

- **GRASP 输出文件的统一加载**：覆盖组态文件、混合系数（二进制）、能级、LSJ 组成、跃迁数据等全部主要文件类型，提供统一的数据访问接口；
- **高层数据提取与格式化**：支持电子组态的自动化简、LSJ 耦合解析、多轮迭代能级合并与跃迁数据后处理，输出直接可用于论文与报告；
- **CSF 的数值化表达**：为每个 CSF 生成固定长度的物理描述符向量，作为后续机器学习建模的特征基础；
- **可视化工具链**：实现耦合通道贡献图、径向波函数对比图、极坐标玫瑰图、四极矩形变图等发表级图表组件；
- **多格式持久化**：统一支持 Parquet / HDF5 / NPZ / CSV / TOML 等格式，兼顾性能与可读性。

### 1.3 怎么做的

**数据加载层**采用"**一文件一 Loader**"的模块化设计：针对 GRASP 每种输出文件实现专用解析器，底层处理二进制字节流或文本解析，顶层通过统一的数据类（dataclass）封装结果。这样既隔离了格式差异，也保证了类型安全。

**分析层**使用 **Polars** 替代 Pandas 作为主数据处理引擎，通过惰性查询与列式存储显著提升大规模能级/跃迁数据的处理性能；对于需要与传统生态对接的场景，保留 Pandas/NumPy 的转换接口。

**CSF 描述符设计**是本阶段的关键方法学产出。其思路是：对每个 CSF 的剥离子轨道（peel subshell），提取三元组 `(电子数, 中间耦合 J, 最终耦合 J)` 作为特征，描述符总长度为 `3 × 子轨道数`。这样得到的向量**具有明确的物理意义**——每一维都对应一个可解释的量子数，既便于机器学习建模，也方便事后对筛选结果做物理核查。

**可视化层**采用配置集中管理的策略：DPI、字体、配色、坐标轴样式等通过统一模块控制，业务代码只关心数据与布局，保证全项目图表风格一致并满足期刊排版要求。

**持久化层**根据数据用途选用不同格式：大规模描述符采用 Parquet（Rust 生成，支持惰性加载）、层级结构数据采用 HDF5、索引与混合系数采用 NPZ、配置与元数据采用 TOML、最终报告采用 CSV。

### 1.4 阶段性成果

- 建成覆盖 GRASP2018 全流程输出的 Python 数据处理框架；
- 形成统一的数据结构规范；
- 沉淀了可复用的可视化组件，支撑后续各类原子物理分析；
- **产出物理约束的 CSF 描述符**——这是从"数据处理"走向"智能筛选"的关键桥梁。

## 第二部分：基于 ANN 的 CSF 智能筛选方法

### 2.1 从第一部分到第二部分的递进关系

GRASP 的精密计算中，CI 展开的 CSF 数量随电子数与激发阶数指数爆炸——对中重元素的高精度计算，完整 CSF 空间可达 10⁶–10⁸ 量级，直接对角化在计算与存储上均不可行。传统做法依靠经验截断或随机采样，存在两难：

- **截断过紧** → 精度损失；
- **截断过松** → 成本不可承受。

第一部分建立的 CSF 描述符提供了将组态表达为数值特征的途径，这使得**用机器学习从已计算的小样本中学习"哪些 CSF 对特定能级贡献显著"、再对未计算 CSF 做贡献预测**成为可能。第二阶段工作即围绕此目标展开。

### 2.2 做了什么

本阶段完成的主要工作包括：

- **设计并实现面向 CSF 筛选的神经网络架构**，包括标准全连接分类器与针对结构化特征的张量网络两种形态；
- **建立多标签一体化训练范式**，单个模型同时学习多个目标能级的 CSF 重要性；
- **构建"GRASP 计算 ↔ ML 筛选"的完整迭代管道**，支持从零开始到收敛的全自动运行；
- **提出混合参考能量排序（Hybrid Reference-Energy Ranking）方法**，将 ML 预测与能级物理约束融合，提升筛选稳健性；
- **引入回归模型分支**，直接预测 log(CI²) 连续值，保留重要度排序的细粒度信息；
- **配套生产级工程支撑**：严格的配置校验、SLURM 集群集成、步骤级检查点与断点恢复、环境感知日志等。

### 2.3 怎么做的

#### 2.3.1 网络架构与训练

采用**双架构 + 自适应选择**的策略：

- **标准全连接 ANN**：适合小样本阶段，结构简单、训练稳定；
- **张量网络**：针对子轨道间高阶交互设计，适合数据充足时提升表达能力。

训练器在运行时根据样本规模与迭代轮次自动选择架构：迭代初期或样本不足时用标准 ANN，后期切换至张量网络。训练流程中集成了 Dropout、早停、混合精度训练、学习率调度等机制。

**多标签一体化训练**是核心技巧：将描述符与多个能级的 0/1 标签拼接为一个张量，单一模型同时输出所有目标能级的重要性概率。相比逐能级训练，样本利用率与训练时间均提升约 N 倍（N 为能级数）。

#### 2.3.2 迭代筛选管道

整个筛选过程被组织为一个闭环：

```
 初始 CSF 空间
      ↓（描述符生成 + 随机采样启动）
 GRASP 计算链（角动量耦合 → 波函数估计 → SCF/CI → 能级提取）
      ↓（回收 CI² 索引，累积到历史数据池）
 ANN 训练（分类或回归）
      ↓（全空间预测 + 自适应阈值 + 扩展比例）
 下一轮 CSF 候选池  ──→（回到 GRASP 计算）
      ↓（收敛则终止）
 最终高精度结果
```

**自适应阈值**：根据已计算样本中"重要 CSF"的实际比例，动态调整 sigmoid 截断，避免过采样或欠采样；

**扩展比例**：当模型输出的重要 CSF 数小于采样目标时，按预设比例扩大候选池，使迭代规模按可控方式稳步增长；

**递进式数据积累**：每轮计算产出的 CI² 值不被丢弃，而是累积到统一的历史数据池中，下一轮训练使用全部历史样本，样本利用充分；

**步骤级检查点**：GRASP 计算链的每个环节都支持单独启停与断点恢复，长达数十小时的计算在失败后可从最近一个完成步骤继续，而非从头开始。

#### 2.3.3 混合参考能量排序（v3.2dev2 的核心方法学创新）

纯 ML 排序只看"模型认为 CSF 有多重要"，但没有利用"计算出的能级本身是否准确"这一物理约束。为此，引入参考能级机制：

1. **计算能隙误差**：对比当前迭代得到的能级与参考值，构造能级对之间的能隙误差矩阵；
2. **物理修正打分**：对候选 CSF 按其对关键能隙误差的贡献（CI 加权）单独打分；
3. **融合排序**：将 ML 重要度分数（权重 0.7）与物理修正分数（权重 0.3）加权组合，作为最终排序依据。

同时提供 `monitor` / `hybrid_rank` / `gate` / `rollback` 四种策略，分别对应"仅监控"、"融合排序"、"门控筛选"、"失败回退"四种使用场景，并通过阈值衰减因子使筛选随迭代逐步收紧，兼顾前期探索性与后期精度。

#### 2.3.4 工程支撑

- **配置系统**：采用 Pydantic v2 构建四级配置（计算设置、服务器设置、路径、步骤控制），所有参数在运行前完成校验，杜绝无效输入；
- **集群集成**：SLURM 作业脚本自动处理分区、节点、MPI 临时路径；
- **环境感知**：自动识别 HPC/SLURM 环境，关闭交互式进度条，改用结构化日志输出，便于作业调度系统回收。

### 2.4 第二阶段的阶段性成果

1. 从"数据处理"到"智能筛选"的闭环管道已在本地与集群环境跑通；
2. ANN 在多能级任务上展现合理的精准率 / 召回率 / ROC-AUC 指标；
3. 自适应阈值与扩展比例机制使迭代规模可控，避免常见的采样震荡；
4. 混合参考能量排序将"计算质量"纳入选择目标，相比纯 ML 方案更稳健；
5. 步骤级检查点支持长时 GRASP 计算的安全重启，显著降低失败成本。

## 两部分工作的递进关系

| 阶段 | 目标 | 核心产出 | 对下一阶段的支撑 |
|---|---|---|---|
| **第一部分** | 打通 GRASP 数据处理链路 | 统一的数据加载/分析/可视化框架；**物理约束 CSF 描述符** | 为 ML 提供高质量特征与标签 |
| **第二部分** | 用 ML 突破 CSF 规模瓶颈 | 多标签 ANN；迭代筛选管道；混合参考能量排序 | 为中重元素真实体系的高精度计算铺路 |

前者是后者的**数据与特征基础**，后者是前者的**方法学升级与科学应用出口**。两部分共同构成面向相对论原子结构计算的"数据处理 + 智能优化"一体化方案。

## 下一步工作计划

1. **科学验证**：选取中重元素（如 La、Nd、镧系离子）代表性能级，系统评估 ML 筛选相对于经验截断的精度-成本曲线；
2. **回归模型深化**：完善回归分支的训练策略，引入不确定度估计（MC Dropout / 模型集成）以指导下一轮采样；
3. **参考能量方法调优**：在更多算例上扫描参考能量相关权重，寻找最佳物理-数据融合策略；
4. **论文产出**：以混合参考能量排序方法为核心整理一篇方法学论文；以具体元素的精密能级计算整理一篇应用论文。
