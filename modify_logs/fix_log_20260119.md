### Issue #1: Type Error in GraspFileLoad.__init__

**文件**: `src/graspkit/data_IO/grasp_data_loader.py`
**行号**: 78-90

#### 问题描述
- 变量 `self.data_file_path` 类型声明为 `Path` 但在 else 分支被赋值为 `None`
- 导致 mypy 错误: `Incompatible types in assignment`
- 运行时潜在错误风险

#### 修改前
```python
# 处理文件路径逻辑
self.file_name = data_file_info.get("file_name", "")
if Path(self.file_dir).is_file():
    self.data_file_path = Path(self.file_dir)
    print(f"Data file {self.data_file_path} loaded.")

elif isinstance(self.file_name, str) and self.file_name:
    self.data_file_path = self.data_file_dir / self.file_name
    print(f"Data file {self.data_file_path} loaded.")
else:
    self.data_file_path = None  # ❌ 类型错误
```

#### 修改后
```python
# 处理文件路径逻辑
self.file_name = data_file_info.get("file_name", "")
self.data_file_path: Path | None = None  # ✅ 初始化时声明类型

if Path(self.file_dir).is_file():
    self.data_file_path = Path(self.file_dir)
    print(f"Data file {self.data_file_path} loaded.")

elif isinstance(self.file_name, str) and self.file_name:
    self.data_file_path = self.data_file_dir / self.file_name
    print(f"Data file {self.data_file_path} loaded.")
else:
    self.data_file_path = None  # ✅ 类型一致
```

#### 修复效果
- ✅ 消除 mypy 类型错误: `Incompatible types in assignment`
- ✅ 消除 mypy 错误: `Attribute already defined`
- ✅ 类型安全: `Path | None` 正确表达可选路径
- ✅ 运行时安全: 避免未定义类型的变量使用

### Issue #5: Redundant/Confusing Methods

**文件**: `src/graspkit/grasp_data_extractor/asfs_data_processor.py`
**行号**: 326-397

#### 问题描述
- `energy_file2dataframe()` 和 `energy_level_2_pd()` 几乎相同
- 唯一区别: 一个使用自定义列名，另一个使用 `header=0`
- 代码重复增加维护负担
- API 混乱且容易出错

#### 修改前
```python
def energy_file2dataframe(self):
    self.saved_csv_file_path = self.raw_data2csv.energy_file2csv()
    self.level_read_df = pd.read_csv(
        f"{self.saved_csv_file_path}",
        header=0,
        names=[...],  # 自定义列名
        dtype=str,
    )
    return self.level_read_df

def energy_level_2_pd(self):
    self.saved_csv_file_path = self.raw_data2csv.energy_file2csv()
    self.level_read_df = pd.read_csv(
        f"{self.saved_csv_file_path}",
        header=0,  # 使用 CSV 原始表头
    )
    return self.level_read_df
```

#### 修改后
```python
def to_dataframe(self, use_custom_columns: bool = True) -> pd.DataFrame:
    """Convert energy file to DataFrame with optional custom column names

    Args:
        use_custom_columns: If True, use custom column names; otherwise use CSV header

    Returns:
        pd.DataFrame: The loaded energy data
    """
    self.saved_csv_file_path = self.raw_data2csv.energy_file2csv()

    if use_custom_columns:
        self.level_read_df = pd.read_csv(
            f"{self.saved_csv_file_path}",
            header=0,
            names=[
                "No",
                "Pos",
                "J",
                "Parity",
                f"Energy_Total_{self.level_parameter}{self.this_as}",
                f"E_as{self.this_as}",
                "Splitting",
                f"Configuration_{self.level_parameter}{self.this_as}raw",
            ],
            dtype=str,
        )
    else:
        self.level_read_df = pd.read_csv(f"{self.saved_csv_file_path}", header=0)

    return self.level_read_df

# Deprecated: Use to_dataframe() instead
def energy_file2dataframe(self):
    """Deprecated: Use to_dataframe() instead"""
    return self.to_dataframe(use_custom_columns=True)

# Deprecated: Use to_dataframe(use_custom_columns=False) instead
def energy_level_2_pd(self):
    """Deprecated: Use to_dataframe(use_custom_columns=False) instead"""
    return self.to_dataframe(use_custom_columns=False)
```

#### 修复效果
- ✅ 统一方法: `to_dataframe(use_custom_columns=True)`
- ✅ 消除代码重复
- ✅ 清晰的 API 设计
- ✅ 保持向后兼容 (旧方法保留为 deprecated)
- ✅ 易于维护和扩展
